# 🚀 Guia Rápido - Check Party

## Para Salões de Festa

### 1. Cadastro
1. Acesse `/admin/register`
2. Preencha dados do salão
3. Crie sua conta

### 2. Criar uma Festa
1. Vá para `/admin/parties/new`
2. Preencha:
   - Nome do aniversariante
   - Data e horário
   - Tema (opcional)
   - Capacidade máxima
3. Clique em "Criar Festa"
4. Anote as credenciais dos pais

### 3. Compartilhar com Convidados
1. Copie o link da festa
2. Envie por SMS/WhatsApp para os convidados
3. Formato: `https://checkparty.com/guest/festa-pedro-2025`

### 4. Gerenciar Confirmações
1. Acesse `/admin/dashboard`
2. Veja confirmações em tempo real
3. Monitore aprovações dos pais
4. Exporte listas quando necessário

### 5. Check-in no Dia
1. Acesse `/admin/check-in`
2. Escaneie QR Codes dos convidados
3. Sistema registra automaticamente

## Para Pais

### 1. Acessar Sistema
1. Receba username e senha do salão
2. Acesse `/pais/login`
3. Faça login

### 2. Aprovar Convidados
1. Veja lista de confirmações
2. Clique em "Aprovar" para convidados conhecidos
3. Clique em "Rejeitar" para desconhecidos
4. Adicione observações se necessário

### 3. Acompanhar
- Dashboard mostra estatísticas em tempo real
- Notificações para novas confirmações
- Contador de vagas disponíveis

## Para Convidados

### 1. Confirmar Presença
1. Clique no link recebido
2. Preencha o formulário:
   - Seu nome completo
   - Número de acompanhantes
   - Observações (opcional)
3. Clique em "Confirmar Presença"

### 2. Aguardar Aprovação
- Você receberá uma mensagem de confirmação
- Aguarde aprovação dos pais
- Confirmação final será enviada

### 3. No Dia da Festa
- Apresente o QR Code recebido
- Check-in será feito automaticamente
- Aproveite a festa! 🎉

## Dúvidas Frequentes

### "Não recebi o link da festa"
- Verifique spam/lixo eletrônico
- Confirme se o número de telefone está correto
- Entre em contato com o salão

### "Minha confirmação não foi aprovada"
- Os pais precisam aprovar todas as confirmações
- Aguarde ou entre em contato com os responsáveis

### "Preciso alterar minha confirmação"
- Acesse novamente o link da festa
- Suas informações aparecerão automaticamente
- Faça as alterações necessárias

### "Esqueci minhas credenciais de pai"
- Entre em contato com o salão
- Eles podem gerar novas credenciais
